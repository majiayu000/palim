# Guard 快照与数字复制优化 — 2026-10-06

基线为 GitHub commit `8572b81`，新版为本报告 measurements.json 中冻结的本地源码。没有修改公开 API、依赖、配置或 crate 版本。此轮未提交或发布。

## 已实现

- 新增成员和 guard 的值复制跳过已规范数字的重复解析，非规范和非法 unchecked Number 仍使用原解析器。规则依据本机 serde_json 1.0.151 的 `scan_integer` / `scan_exponent`；回归覆盖任意字符串、浮点构造、大整数、指数和负零。当前依赖的六个 from_f64 定向样本均已规范，不把“from_f64 会被改写”作为已证实的事实。
- 深度检查改为先验证限额再递归访问子容器，深度最多 128，避免把宽对象的所有子容器一次性压入堆栈。保留最大深度、错误文案和验证顺序；128 KiB 线程上的 0/1/127/128 层边界与宽容器测试通过。
- guard 复用已经 test 过的容器及其子树；替换/删除边界和数组插删/移动会撤销对应记录。仅记录容器，避免标量字段形成庞大的索引。前缀重放重建相同记录，生成器和成本模拟共同执行去重规则。
- 普通带 tests 的完全不相交原始值数组使用一个完整基线 test 加位置替换，保留对额外数组项的拒绝。配置的自定义匹配和投影仍走原路径。
- guard 读取改用现有 jsonptr Pointer 的 parent/resolve，避免普通路径上 serde_json::Value::pointer 的分段字符串复制。不是对仓库所有 pointer 调用的替换。

## 全部 fixture 的同次测量

Core：已解析 Values → 生成 → 销毁输出。Pipeline：同一紧凑输入字节 → 解析左右 → 生成 → 紧凑 UTF-8 序列化 → 销毁。每配置 3 个独立进程，每进程 3 次热身、10 ms 校准、9 批测量；交替先后顺序，编译/测试/fuzz 在计时前完成。主矩阵涵盖旧 evidence 的全部 16 份 fixture，额外含三个旧版增长对照，共 324 个计时进程、17 个独立分配探针。

## 仍有的差距

- 100k 新增对象 plain：39.475583 → 33.239958 ms，json-patch 为 23.519041 ms，新版仍约慢 1.41 倍。复制后的规范化树遍历仍存在；本轮没有合并到入口扫描，也没有据分配对齐宣称 CPU 对齐。
- 成员迁移 plain：2.977500 → 2.684646 ms，json-patch 为 2.611552 ms，差距约 2.8%；Pipeline 基本没改善。
- 百万旋转 plain：旧 202.951125、新 213.356458、json-patch 117.765833 ms。前后进程范围重叠，当前正式表仍显示新版约慢 5.1%，不能声称无退化。早期 numeric-only 三版本 5 对复测也完整保留，不择取它的较好结果覆盖正式表。移动检测尚未优化。
- 同一百万输入，Palim plain 的补丁 44 字节，json-patch 为 58,888,891 字节。更小输出和更高生成成本是两个独立测量，不能用前者宣称后者领先。
- opt 的标量 100k 约 166.6 ms，213 万次分配，优化器本身仍是后续目标。Pointer 优化仅覆盖 guard 读取热点；无跨语言新数据，不沿用旧 JS/Go 报告宣称领先。
- 单台 M2 Max、排序 Map、warm 测量。桌面与系统负载没有隔离，尤其百万数组进程间波动较大；无 cold、并发、尾延迟、跨平台和 RSS 数据。

## 复现

新增证据使用 JSON 和脚本，没有再提交大型 ZIP，也没有改写旧仓库历史。脚本从旧 evidence ZIP 读取固定 fixture 和基线，从本报告的冻结源码构建新版；两边 Cargo.lock 固定。

```sh
python3 results/guard-and-number-20261006/run.py --quick
python3 results/guard-and-number-20261006/run.py
```

quick 只用于重建和小输入复现核验；正式数据在 measurements.json 中。运行目录位于新建的临时目录，脚本会打印路径。

已在新临时目录执行 `run.py --quick`：冻结源码与 16 份 fixture 指纹核验、两份 probe 重建、18 个计时进程及 3 个分配探针通过。正向/逆向恢复通过，exit 0；回执见 measurements.json 的 replay_validation。
